# Plataforma de Empleabilidad Juvenil

Proyecto de la plataforma para conectar jovenes con oportunidades de empleo.

## Trazabilidad Jira-GitHub

Este repositorio esta vinculado al proyecto PEJ en Jira mediante la app GitHub para Jira. Cada rama, commit y Pull Request que incluya el ID de un ticket (ej. PEJ-5) queda enlazado automaticamente en la seccion Development del issue correspondiente.
